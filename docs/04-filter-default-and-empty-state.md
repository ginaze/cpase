# Dokumentasi: Filter dan Kondisi Kosong

Penanganan tampilan daftar tugas berdasarkan filter status dan kondisi kosong.

## Fitur

- Rute hash untuk memfilter daftar: `#/semua`, `#/aktif`, `#/selesai`.
- Filter default: `#/aktif`.
- Pesan kosong: "Belum ada tugas" (jika daftar kosong) atau "Selamat, semua tugas telah selesai" (jika daftar terisi tapi semua selesai).
- Fitur pencarian otomatis yang muncul jika jumlah tugas > 5.
